# Hades Canyon 向け NucLED

Intel Hades Canyon NUC 用の macOS メニューバーアプリです。LED モードの手動切り替えと、毎日のオン／オフ時刻を設定できます。アプリは本プロジェクトの IOKit カーネルドライバ経由でマザーボードの WMI インターフェイスを操作します。ドライバがない場合、操作が成功したようには表示せず、利用できないことを通知します。

[简体中文](README.md) · [English](README-en.md) · [日本語](README-ja.md) · [한국어](README-ko.md)

## 機能

- メニューバーのドクロアイコンをクリックして操作パネルを開きます。
- LED インジケーターモードを手動で有効／無効にし、ハードウェアを読み戻して結果を確認します。
- 毎日の点灯／消灯時刻を設定できます。スリープ復帰、時計やタイムゾーンの変更後にスケジュールを再確認します。
- ログイン時の起動を選択できます。アプリを終了するとスケジュールを一時停止し、再起動後に再開します。
- LED を無効にする前に各ゾーンのモードを保存し、検証してから順に復元します。

本プロジェクトが変更するのはファームウェアの LED モードです。色や明るさは制御しません。Power State モードの読み取りだけでは、LED が目視できる明るさで点灯していることを確認できません。

## 対応機器とシステム

- 対象：検証済みの `AMW0` WMI インターフェイスを持つ Intel Hades Canyon NUC8i7HVK / NUC8i7HNK。
- アプリ：macOS 13 以降。Swift Package Manager でビルドします。
- ドライバ：Intel `x86_64`、現在の最低ビルド対象は macOS 15.5 です。macOS 15.5 の Hackintosh でのみ検証済みです。アプリが起動しても、ドライバがそのシステムで読み込めるとは限りません。

汎用 Mac LED コントローラーではありません。Apple Silicon と他の NUC モデルには対応していません。

## アプリのインストール

[GitHub Releases](https://github.com/winglight9/NucLED/releases/latest) から `NucLED-Installer.dmg` をダウンロードして開き、`NucLED.app` を「アプリケーション」へドラッグします。「アプリケーション」から起動し、メニューバーのドクロアイコンをクリックしてください。Dock アイコンや独立したメインウィンドウはありません。メニューバーに空きがない場合は、macOS の非表示／オーバーフロー項目を確認してください。

現在の DMG はアプリのみで、ドライバ、ドライバインストーラー、アンインストーラーは含まれません。ソースからビルドされる KEXT は未署名です。開発機では独自のテスト用セキュリティ設定を使用しており、通常の macOS セキュリティ設定で読み込めることを示すものではありません。macOS 11 以降のサードパーティ KEXT はユーザー承認と再起動が必要で、Apple は一般的なソフトウェアに KEXT を推奨していません。[Apple の KEXT 展開ガイド](https://support.apple.com/guide/deployment/system-extensions-in-macos-depa5fb8376f/web)および [`Driver/README.md`](Driver/README.md) を参照してください。現状はハードウェア検証／開発プレビューであり、一般ユーザー向けの完全なワンクリックインストーラーではありません。実行のために SIP 全体を無効にしないでください。

アプリは現在ローカルのアドホック署名で、Developer ID 署名および Apple 公証はありません。macOS が開発元を確認できないと警告する場合があります。配布元を信頼し、公開ファイルを確認したうえでのみ、Finder の Control キーを押しながらクリックして「開く」を選択してください。公開配布に必要な署名と公証については [Apple の公証ガイド](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)を参照してください。ログイン時の起動にはアプリを「アプリケーション」に置き、「システム設定 → 一般 → ログイン項目」での承認が必要な場合があります。

## ソースからビルド

Xcode Command Line Tools と macOS SDK が必要です。

```sh
swift build --configuration release
./script/build_dmg.sh
```

スクリプトは `dist/NucLED-Installer.dmg` を作成します。アプリのアドホック署名は Developer ID 署名や公証の代わりにはなりません。

ドライバ bundle のビルド：

```sh
make -C Driver bundle
```

このコマンドは未署名の `Driver/.build/NUCLEDDriver.kext` をビルドするだけで、**インストールや読み込みは行いません**。ドライバはカーネルコードを含み、対応する Intel Hades Canyon 専用です。先にドライバ説明を読み、インストールのリスクを確認してください。

## ハードウェア検証

開発用 Hades Canyon で実機 WMI の書き込みと読み戻しを一度確認しました。6 つの LED ゾーンを読み取り、個別に無効化して確認し、元のモードへ戻した後に再度読み戻しました。他の機器での互換性を保証するものではなく、カメラや光センサーで実際の発光は確認していません。公開 DMG はアプリのみで、一般ユーザー向けの署名済みドライバパッケージはありません。

## トラブルシューティング

- **アプリのアイコンをクリックしてもウィンドウが出ない：** メニューバーアプリです。メニューバーのドクロをクリックして操作パネルを開いてください。
- **ドクロが見つからない：** NucLED の実行状態を確認し、非表示のメニューバー項目も確認してください。
- **ドライバが利用できないと表示される：** `NUCLEDDriver` が読み込まれていることを確認してください。アプリにはドライバインストーラーが含まれていません。
- **切り替えに失敗する：** パネルの状態メッセージを確認してください。読み戻しに失敗した場合、アプリは成功とみなさずエラーを表示します。

## ソースコードとライセンス

リポジトリには macOS アプリ、ドライバソース、ビルドスクリプト、アイコン素材が含まれます。ドライバのインターフェイスとセキュリティ境界は [`Driver/README.md`](Driver/README.md) を参照してください。現在オープンソースライセンスは設定されていません。ソースを公開していても、複製、改変、再配布の許可を意味しません。
