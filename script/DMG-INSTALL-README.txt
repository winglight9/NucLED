冥王 LED 安装说明

版本 1.0.4：优化时间输入的选区显示和下一次定时动作提示；调整菜单栏骷髅图标的大小与单色呈现。

1. 将「NucLED.app」拖到右侧的「Applications」文件夹。
2. 等待复制完成后，推出此磁盘映像。
3. 从「应用程序」文件夹打开「NucLED.app」。

如果 macOS 提示无法验证开发者，请在「应用程序」中按住 Control 键点按 NucLED.app，选择「打开」，再确认一次。

菜单栏图标提供 LED 手动开关、定时开关和登录时启动选项。
NucLED 是菜单栏应用，不会弹出独立窗口或显示 Dock 图标。打开后请点击屏幕顶部菜单栏中的骷髅图标进入控制面板。
控制 LED 需要本机已安装并获准运行的 NUC 冥王峡谷驱动。
此版本使用本机临时签名，未使用 Developer ID 签名或 Apple 公证；登录启动须在「应用程序」中运行，并可能需要在系统设置“通用 › 登录项”批准。
